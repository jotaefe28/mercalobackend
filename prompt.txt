// ==================== NUEVA FUNCIONALIDAD: REDENCIÓN DE PUNTOS ====================

/**
 * REQUERIMIENTO CRÍTICO: Sistema de Redención de Puntos
 * 
 * La lógica actual NO contempla la redención de puntos como descuento en ventas.
 * DEBE implementarse:
 * 
 * 1. Endpoint de redención:
 *    POST /api/points/redeem
 *    Body: {
 *      customer_id: "uuid",
 *      points_to_redeem: 150,
 *      sale_total: 200.00
 *    }
 * 
 * 2. Validaciones de redención:
 *    - Cliente debe tener suficientes puntos
 *    - Puntos a redimir no pueden exceder el total de venta
 *    - Conversión 1:1 (1 punto = $1 descuento)
 * 
 * 3. Stored procedure para redención:
 *    CALL redeem_points(customer_id, points_amount, sale_id)
 *    - Actualizar customer_points_log con cambio negativo
 *    - Actualizar current_points del cliente
 *    - Registrar en sale el descuento aplicado
 * 
 * 4. Modificar registro de ventas:
 *    - Agregar campo points_redeemed a sales
 *    - Calcular total_final = subtotal - points_redeemed + taxes
 *    - Mostrar descuento en receipt/factura
 * 
 * 5. Historial de redenciones:
 *    - Log en customer_points_log con reason: 'Redemption'
 *    - change_amount negativo
 *    - Referencia a sale_id correspondiente
 */
